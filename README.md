# Diamond Price Prediction using Snowflake

## Project Overview
End-to-end machine learning regression project implemented using Snowflake.

## Dataset
Diamonds Dataset from Kaggle.

Dataset size: 53,940 rows.

## Models
- Linear Regression
- Random Forest Regressor

## Best Model
Random Forest Regressor

## Evaluation
- MAE: 276.79
- RMSE: 560.30
- R²: 0.9803

## Snowflake Objects
- Database: DIAMOND_PRICE_ML
- Schema: ML_WORKFLOW
- Raw table: DIAMONDS_RAW

## Application
Interactive Streamlit application for exploring diamond prices and model performance.
